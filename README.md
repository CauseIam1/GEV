This document defines the overarching architecture, operational rules, and integration framework for embedding God's Eye View (GEV) into the Polaris ecosystem as our primary geospatial intelligence, mobile presence, and situational awareness layer.
1. System Purpose & Vision
God's Eye View (GEV) is a near-real-time geospatial visualization engine built on CesiumJS that provides a global and local operational picture.
 * Primary Objective: Serve as cooperative spatial intelligence for the Polaris ecosystem, bridging global map rendering, tactical field operator tracking, and vehicle node telemetry into a single unified interface.
 * The Dual-Input Mandate: GEV supports frictionless multi-modal interaction—allowing the operator to converse hands-free via voice (leveraging LGI and FreeRoam edge nodes routed through the Polaris Gateway) or execute precise typed commands directly through the full-width Polaris command bar docked along the bottom of the GEV interface.
 * Autonomous Control: Polaris is equipped with native tool dispatchers capable of manipulating GEV's map state programmatically (centering coordinates, toggling data layers, and querying objects).

6. Polaris Tool Dispatcher Extensions (gev_tools.py) — PENDING module; server bridge LIVE
To give Polaris autonomous control over the mapping interface, a new tool module (gev_tools.py) is added to the Polaris Gateway's execution tools registry. The GEV server side of this bridge is already LIVE: POST /api/gev/command accepts {"op","args"} and broadcasts 'gev_update' into room gev_dashboard (known ops: set_center, toggle_layer, query_object, set_focus_operator); gateway calls land on http://gev:5001 via the pre-wired GEV_SERVICE_URL.
 * Core Tool Schemas:
   * gev_set_center: Programmatically pans and zooms the globe to specified geographic coordinates, named waypoints, or live asset positions (e.g., operator mobile position).
   * gev_toggle_layer: Enables or disables specific visualization layers (e.g., weather, traffic, custom asset markers, vehicle/mobile telemetry trails).
   * gev_query_object: Retrieves metadata and status reports for selected entities currently rendered on the globe (viewer replies via the 'gev_census' socket event; the server serves the latest at GET /api/gev/census).
   * set_focus_operator (LIVE, server-accepted): Flies the camera to the live operator fix streamed from the Burst Receiver (keyboard 0 does the same on the viewer).
 * Prompt Integration: The system prompt and few-shot examples are updated to recognize spatial and map-based commands, enabling natural language execution (e.g., "Polaris, center the map on my current location and show me the active telemetry").

A. HTTP Surface
 * GET / — operator viewer HUD; template-injected GEV_BURST_WS_URL, GEV_GATEWAY_URL, GEV_ION_TOKEN.
 * GET /api/gev/health — {"status":"online", "service":"gev", viewers_connected, commands_recorded, ion_token_configured, uptime_seconds, last_command}. viewers_connected is read from the Socket.IO room table and reports -1 when unknown (never fabricated).
 * POST /api/gev/command — body {"op","args"}; broadcasts as 'gev_update' to room gev_dashboard; unknown op → 400 with known_ops; malformed JSON → 400; every accepted op lands in a 100-entry audit deque; commands are NOT replayed to late joiners; a tool-side error never crashes the bridge.
 * GET /api/gev/census — last viewer census with updated_epoch. GET /api/gev/history — command audit trail.
 * Ops registry: set_center ("lon","lat","height"?) · toggle_layer ("layer","enabled") · set_focus_operator · query_object ("query"?).
B. Socket.IO Wire Contract
 * Channel 1 (viewer → this service): on connect the server emits 'gev_status' {service, ops, ts_epoch}; the viewer emits join_gev/leave_gev (room gev_dashboard), consumes 'gev_update' → dispatchCommand (camera flyTo / layer toggle / focus / census), and emits 'gev_census' carrying camera lon-lat-height, layer states, ion-token flag, and the live operator fix when present.
 * Channel 2 (viewer → Burst Receiver :8083, the join_radar mirror): joins gev_dashboard, consumes 'gev_location' → operator bear avatar (heading-rotated sprite; live ⇄ stale swap at 120 s) + fix-age HUD; the GPS dot goes warn on disconnect.
