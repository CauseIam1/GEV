This document defines the overarching architecture, operational rules, and integration framework for embedding God's Eye View (GEV) into the Polaris ecosystem as our primary geospatial intelligence, mobile presence, and situational awareness layer.
1. System Purpose & Vision
God's Eye View (GEV) is a near-real-time geospatial visualization engine built on CesiumJS that provides a global and local operational picture.
 * Primary Objective: Serve as cooperative spatial intelligence for the Polaris ecosystem, bridging global map rendering, tactical field operator tracking, and vehicle node telemetry into a single unified interface.
 * The Dual-Input Mandate: GEV supports frictionless multi-modal interaction—allowing the operator to converse hands-free via voice (leveraging LGI and FreeRoam edge nodes routed through the Polaris Gateway) or execute precise typed commands directly through the full-width Polaris command bar docked along the bottom of the GEV interface.
 * Autonomous Control: Polaris is equipped with native tool dispatchers capable of manipulating GEV's map state programmatically (centering coordinates, toggling data layers, and querying objects).

A. HTTP Surface

 * Channel 1 (viewer → this service): on connect the server emits 'gev_status' {service, ops, ts_epoch}; the viewer emits join_gev/leave_gev (room gev_dashboard), consumes 'gev_update' → dispatchCommand (camera flyTo / layer toggle / focus / census), and emits 'gev_census' carrying camera lon-lat-height, layer states, ion-token flag, and the live operator fix when present.
